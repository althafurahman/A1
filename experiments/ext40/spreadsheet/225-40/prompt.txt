I need a macro that can go through cells in a column and replace the values of duplicate entries with a predefined value. I found some code that nearly achieves this by replacing duplicates with an asterisk, but I would like the macro to also ignore empty cells while processing the data. For reference, I have included the following example code and an attached Excel sheet: Sub replacedupl_with_star() Dim a, lastrow As Long lastrow = Cells(Rows.Count, 2).End(xlUp).Row For i = 1 To lastrow a = WorksheetFunction.CountIf(Range("B1:B" & lastrow), Cells(i, 2)) If a > 1 And Cells(i, 2) <> "*" Then For k = 2 To a Range("B" & i).Resize(k - 1, 1).Value = "*" Next k End If Next i End Sub.
